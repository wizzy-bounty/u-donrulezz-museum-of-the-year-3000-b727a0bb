# Museum of the Year 3000

Entry for the make.fun competition "Museum of the Year 3000": a one-line museum label written from the year 3000 for an ordinary object of today — a disposable fork, preserved unused. The label treats the fork's perfect condition as evidence about the meal it never survived.
